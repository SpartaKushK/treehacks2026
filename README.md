# People API — Agent-to-Agent Human Endpoints

**TreeHacks 2026** | OpenAI AI Track + Anthropic (Claude) Track + Vercel Track + Greylock Multi-turn + OpenEvidence Healthcare

Each human has a canonical agent endpoint (`/u/:handle`) discoverable via a registry, with scope-based permissions and Ed25519-signed requests.

## Quick Start

```bash
pnpm install
cd apps/web && npx prisma db push && cd ../..
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) (or whatever port Next.js assigns).

The database auto-seeds on first API request with demo users (pari, alex, dr_smith).

## Demos

### 1. Multi-turn Scheduling Negotiation (pari <> alex)
Click **"I want coffee with Alex next week"** — completes in <10s showing:
- Registry lookup for both agents
- Ed25519 signature signing + **VERIFIED** badge
- Policy check (allowed callers + required scopes)
- 3-turn propose / counter / confirm negotiation
- Final booking confirmation
- LLM provider badge (OpenAI or Claude) on planner steps

### 2. Healthcare `/health_summary`
Click **"Doctor agent: fetch Pari health summary"** to get:
- 30-day computed analytics (sleep, steps, medication adherence, symptoms)
- Patient-friendly explanation generated by LLM
- Full trace with signature verification

### 3. Payment Gating (402)
Uncheck **"Premium scope"** on the health demo and click again — returns:
- HTTP 402 with checkout URL and price
- Payment required banner in UI with checkout link

### Provider Switch
Toggle **OpenAI / Claude** on either demo. Trace labels which provider was used. Falls back to deterministic mode if no API keys set.

## Environment Variables

Copy `.env.example` to `.env.local`:

```bash
cp apps/web/.env.example apps/web/.env.local
```

| Variable | Required | Description |
|---|---|---|
| `OPENAI_API_KEY` | No | Enables OpenAI LLM planner (GPT-4o-mini) |
| `ANTHROPIC_API_KEY` | No | Enables Claude LLM planner (Sonnet) |
| `NEXT_PUBLIC_BASE_URL` | No | Defaults to `http://localhost:3000` |

Without API keys, both planners fall back to deterministic logic — the full demo still works end-to-end.

## Deploy to Vercel

1. Push this repo to GitHub
2. Import in [vercel.com/new](https://vercel.com/new)
3. Set root directory to `apps/web`
4. Add environment variables (OPENAI_API_KEY, ANTHROPIC_API_KEY)
5. Deploy

Note: SQLite runs locally; for production, switch the Prisma datasource to Postgres.

## API Surface

| Endpoint | Method | Description |
|---|---|---|
| `/api/registry/register` | POST | Register a human agent |
| `/api/registry/lookup/:handle` | GET | Lookup agent by handle |
| `/api/u/:handle/caps` | GET | List capabilities + policies |
| `/api/u/:handle/invoke` | POST | Invoke capability (signed) |
| `/api/demo/schedule` | POST | Run scheduling negotiation |
| `/api/demo/health` | GET | Run health summary demo |
| `/api/demo/trace/:traceId` | GET | Retrieve full trace |
| `/api/demo/seed` | POST | Re-seed database |

## Architecture

```
/
  apps/web/          Next.js (App Router) — UI + API routes
    app/api/         All API endpoints
    components/      TraceViewer, ProviderToggle, JsonView
    lib/             Core logic (crypto, policy, trace, seed, people)
    prisma/          Schema + SQLite
  packages/shared/   Types, Zod schemas, LLM abstraction, canonical JSON
```

## Tech Stack
- **Monorepo**: pnpm workspaces
- **Web**: Next.js 14 (App Router)
- **DB**: SQLite + Prisma
- **Signing**: Ed25519 via tweetnacl
- **LLM**: OpenAI (Chat Completions) + Anthropic (Messages API)
- **Schemas**: Zod

## Prize Alignment

- **OpenAI AI Track**: Provider-switchable LLM planner with JSON schema enforcement
- **Anthropic (Claude) Track**: Claude planner integration, deterministic fallback, Claude Agent SDK-ready
- **Vercel Track**: Next.js App Router, deployed on Vercel
- **Greylock Multi-turn**: 3-turn scheduling negotiation with full trace transparency
- **OpenEvidence Healthcare**: Structured health analytics from 30-day demo data + patient-friendly explanation
- **Modal Sandbox** (optional): Capability handlers are isolated and could be sandboxed
